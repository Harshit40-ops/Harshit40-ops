## 🚀 Featured Project

### 🛡️ [SatyaCheck](https://github.com/Harshit40-ops/satyacheck) &nbsp;·&nbsp; [**▶ Live Demo**](https://harshit3114-satyacheck.hf.space)

A **deployed multi-modal deepfake & AI-content detector** for WhatsApp forwards — checks images, voice notes, and video, and returns an evidence-first verdict, not just a score.

- 🧠 **3-model AI-image committee** + face-deepfake specialist + classical forensics (ELA, FFT), fused with a **two-witness rule** that structurally prevents false accusations
- 📉 **Measured research**: quantified how WhatsApp compression drops detection recall 94% → 75% while *raising* precision — with a full IEEE paper, ROC/AUC, and an ablation study
- 🔍 Explainable: occlusion focus maps, per-second video timelines, per-face attribution, spectrograms
- 🌐 Bilingual (English/Hindi) · spoken verdicts · installable PWA · live on a free CPU tier
